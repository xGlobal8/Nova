# Design library

74 ready-made `DESIGN.md` design systems from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, see `LICENSE`), one folder per website style.

The active style for this project is the root `DESIGN.md` (currently Apple). To switch styles, copy another one over it, e.g.:

```sh
cp designs/linear.app/DESIGN.md DESIGN.md
```
